# 菜单

`client/scripts/ui/system_menu.gd`，挂在主场景下面（`main.sysmenu`），自己占第 8 层：界面（1）、开局纸条（4）、搭伴小游戏（5）上面，转场（50）下面。

## 怎么打开

- 右上角那颗三道墨线的小按钮。河畔里在「对门」那张牌底下（`BUTTON_TOP_WORLD`，和原来的音量按钮同一个位置），菜单页和离线逛逛时在角上。弹窗出来、人生长卷那一页让开。
- 手机的返回键：`project.godot` 里 `quit_on_go_back=false`，返回键不再直接退出游戏，交给菜单（`NOTIFICATION_WM_GO_BACK_REQUEST`）。
- 电脑上的 Esc（`ui_cancel`）。输入框有焦点时 Esc 不开菜单。
- 有的手机返回键会同时来一个按键和一个通知：0.25 秒里只认一回。

## 里面有什么

河畔里叫「歇一会儿」（钟不会自己走，你不点这一段就等着你，所以不叫暂停）：

- 左边压暗的那一半：两个圆（亲近越多叠得越多，和 HUD 上的两个圆一个意思）、两个人的名字、几岁几点、亲近默契。
- 右边一张从右边滑进来的纸：
  - **声音**：音乐 / 街上 / 动静三条音量（`InkSlider`，一把十一道刻度的尺，五格一档，拖到底写「关」）。松手时放一声那条总线上的声音。存法见 [AUDIO.md](AUDIO.md)。
  - **这一世**（联机和网页单机）：成长账、下一道关，就是 HUD 上点那两块弹出来的同一张卡。
  - **接着过**，底下一排：回大厅（`main.leave_to_lobby()`：离开房间、回到挑人生线那页；单机回「一个人过」）、回标题、退出游戏（点两下；网页版没有）。

标题、大厅这些页叫「设置」，只有声音、回去、退出。

菜单开着时河畔里点不动（`main._process` 里 `world.controllable` 看 `sysmenu.is_open()`）。
