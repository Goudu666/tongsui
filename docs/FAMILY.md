# 成家和下一代

一句话：三十岁往后，一天五段时间又多了一个要它的人。押在孩子身上，孩子的关口过得去；押在自己身上，自己的四十五、七十过得去。两样都要，就得找对门搭伴。

守着核心循环（关口冲刺，见 docs/GROWTH.md）：新东西都挂在关口上，不另起货币、进度条、关系值。孩子用的是和人一样的属性（体魄 / 心智 / 魅力），不是新属性；孩子的关口和人的关口是同一套 milestone。

## 一、关系不是一条路

两个同岁的对门，长大以后可以是发小、知己、伴侣，也可以走散。不强制恋爱。

- 二十八岁一道关「成家」（`m_wed`，看亲近 close）。选项：跟对门过（线高）/ 和别人成家 / 做一辈子的老朋友（线低）/ 一个人过（兜底）。两人选同一个才成：都选跟对门过 → `p_married`；都选老朋友 → `p_confidant`；一个想跟对门过、一个没有 → 错位，`p_missed`。
- 已经 `p_married` 或 `married_other` 的人不过这道关（requires.notFlags）。旧的 y_fireworks / y_wedding 照旧是早一点成的路。
- `p_confidant`（知己）是和伴侣并列的好结局，不是安慰奖：结局、街坊记住的事、老年事件都要认它。

## 二、孩子

- 谁有孩子：身上有 `has_kid` 标记的人。拿到 `has_kid` 的那一刻服务器给他生一个孩子（`LifeState.kids`）。两口子（`p_married`，对门还活着）是同一个孩子，对门也一起拿 `has_kid`。
- 孩子的属性：出生时按爹妈属性折一点（`rules.yaml` 的 `family` 一节），以后靠爹妈押时间长；不押也会自己长一点（每个日子一点点）。
- 孩子几岁 = 爹妈现在的岁数 − 生孩子那年爹妈的岁数（两口子按先拿到 has_kid 那个人算）。
- 两家各有一个孩子、出生差不到两岁：两家孩子也同岁。服务器给两个大人都打 `kids_same_age`。

### 行动（content/map.yaml）

行动加一个字段 `kid: { mind?: n, body?: n, charm?: n }`：这件事长的是孩子，不是自己（自己不长，照样累、照样花钱）。`requires.kidAge: [lo, hi]`：孩子在这个岁数段才能做（没孩子做不了）。

- 同一个点同一件事两个人一起做 = 搭伴，孩子那份也按搭伴倍率长。两家各带各的孩子一起写作业，两个孩子都长得快一点——这是两家互相需要的理由。
- 两口子一起带同一个孩子，两份都长在这一个孩子身上。

### 孩子的关口（content/events/kid_gates.yaml）

milestone 加一个字段 `kidAge: n`：孩子到了这个岁数之后，爹妈的第一个「没有自己关口」的日子早上发生。只有有孩子的那个人过（两口子两个人一起过，可以共鸣）。

- `score` 里用 `kid_mind` / `kid_body` / `kid_charm` 读孩子的属性，显示照百分制。
- 选项打的标记落在爹妈身上，统一 `kid_` 开头（`kid_key_school`、`kid_uni` …），之后的事件、结局、传承读它。
- 孩子的关口进纸带（lifeGoal），和自己的下一道关并排：一眼看出今天该押谁。
- 关口：孩子 6 岁上小学、12 岁小升初、15 岁中考、18 岁高考。中老年一个日子是三年，所以基本一个日子一道。

## 三、和传承接上

- 孩子关口的共同标记（两口子共鸣）写成 `p_kid_*`，下一世出生带 `leg_p_kid_*`（隔世的事读，不给数）。
- 两家孩子同岁、一起长大的共同标记 `p_kids_tongsui`：下一世的两个孩子是上一世那两个孩子的孩子——不说破，只让他们撞见。
- 老物件 / 街坊记住的事按 docs/LEGACY.md 的约束：属性最多半点，记住的事无奖励、只看一世之内的事。

## 四、数值口径（tools/ 校准）

- 一个认真押孩子的人（三十到四十五岁空闲时段一半给孩子），孩子高考线够得着；不押的，孩子靠自己长，够不着高线，够得着兜底。
- 押孩子的代价是自己：四十五「去争那个位子」够不着的会多。和对门搭伴带孩子，两头都顾得上一点。
- 当了爹妈的比例 50%~65%（原来 9.7%）。

## 五、协议和存档

- `LifeState.kids?: Kid[]`，`LIFE_VERSION` +1，`lifeUpgrade` 补空数组；`lifeRepair` 不用管（不指向内容 id）。
- WORLD 每个人加 `kid`（没有就不发）：`{ name, age, stats: { body, mind, charm }, shared }`，客户端显示孩子卡片。
- 内容构建白名单加 `kid`（行动）、`requires.kidAge`（行动）、`kidAge`（milestone），以及 ScoreWeights 的 `kid_mind` / `kid_body` / `kid_charm`。
