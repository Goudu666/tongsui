# 《同岁》文风手册：天津做底色

> 天津是这栋楼的地址，不是这个游戏的表演。

这份手册管《同岁》里所有文字和场景细节的写法：事件、街坊、同框文案、结局、地图上的小物件。
它从天津文学里学的是**分寸和手法**，不搬原作的人物和句子。文中的示例文案都是为本项目原创的。

玩法方向由"重审核心玩法"的工作来定，这份手册只管怎么写。玩法怎么变，下面的规则都适用。

| 你要做的事 | 先看 |
| --- | --- |
| 任何文字 | §1 克制，这一节优先于其他所有章节 |
| 写 / 改事件 | §4 声口、§9 规范和对照示范 |
| 写街坊、家庭线 | §5 |
| 画地图、加小物件 | §6、§7、§10 |
| 交稿前 | §12 自检 |

---

## 1. 克制

**《同岁》首先是两个人过一辈子的游戏，其次才发生在天津。** 天津味要让人事后才觉出来，不能一进门就扑到脸上。

还有一个实际的理由：人生模拟会反复开局。方言梗和抖机灵读第二遍就腻，平实的白描读第五遍还耐读。

### 1.1 三层，越往下越少用

| 层 | 是什么 | 用多少 |
| --- | --- | --- |
| **人情** | 这里的人怎么待人：热心，嘴上不饶人，吵完不记仇，难处先拿自己开涮 | 一直都在。它不需要任何方言词 |
| **物件和作息** | 早点、楼道、暖气片、海河、鸽子、白菜 | 常用，用普通的叫法 |
| **方言和习俗** | 天津话、岁时讲究、本地才有的叫法 | 很少，当佐料 |

写得像天津，九成靠前两层。

### 1.2 预算

这些是硬数，写完可以数。

- **旁白和玩家的选项不用方言词。**
- **街坊的对白：** 一个事件至多一个方言词，而且只从 §13 的小词表里取。全部事件里带方言词的不超过四分之一。
- **本地才有的东西**（某样吃食、某个习俗、某个叫法）：一个事件至多一样。一套煎饼果子连同里头的果子、果篦儿、鸡蛋算一样。
- **习俗只留一处：二月二剃头。** 其余要靠本地人核实才敢写的习俗和讲究（喜事丧事的礼数、岁时的吃法、行当里的老例儿）一律不写。冬天搬白菜、过年放炮、夏天上楼顶这些是过日子，不算习俗，照常写。
- **有"绝活"的街坊：** 全楼至多三位，写得平常，不神化。
- **不解释。** 需要加注才懂的词和习俗，不用。
- **煎饼果子的规矩要写，但只写成早点铺的日常。** 见 §1.6。

### 1.3 刻意的征兆

出现下面任何一条，就是用力过猛了：

- 一句话里有两个方言词，或者感叹词开头（好么、嚯）。
- 人物一出场先报外号和绝活。
- 旁白学说书人（话说、且说、列位）。
- 一个事件存在的理由只是展示一样风俗。
- 每条结尾都想逗一下。
- 用"天津人就是……"下判断。
- 外号满天飞。街坊按身份或者姓来叫就行（§4.4）。
- 影视剧和网上用烂的天津梗。

### 1.4 三个测试

1. **删词测试：** 把天津词全换成普通话，这条还好不好？不好，说明它是靠方言撑着的，重写。
2. **两个人测试：** 这条写的是你俩之间的事，还是天津的事？后者只能是背景。
3. **第五遍测试：** 这句话在第五次人生里再读到，还行吗？

多数事件搬到任何一座北方老楼都成立，这没有问题。十条里有两三条让天津露一下面就够了。

### 1.5 对照

| 用力过猛 | 克制 | 天津在哪儿 |
| --- | --- | --- |
| 「好么！介煎饼果子倍儿香！」摊主一手磕俩蛋，嘴里不停。 | 早点铺排着队。轮到你俩，老板娘没问，直接磕了两个鸡蛋。 | 在"没问"里。她记得每个孩子怎么吃 |
| 二月二龙抬头，按老例儿这天要剃头，还要…… | 二月二，剃头的在楼下支了摊。你俩一前一后坐上去，下来的时候谁也不看谁。 | 习俗只是场合，事是两个人的 |
| 修车爷爷人称某某，补胎有三不修的规矩…… | 修车爷爷补胎不用水盆，凑到耳朵边转一圈就找着了。你问他怎么听的，他说修了三十年了。 | 在一个不当回事的能耐里 |
| 「嘛钱不钱的，乐呵乐呵得了！」 | 钱没借着。他在楼门口站了一会儿，说：「今儿晚上吃顿好的。」 | 在难处里照样把饭吃好 |

### 1.6 煎饼果子的规矩

这是全游戏唯一一条摆在明面上的本地规矩，也是河畔里最日常的一件事：

- 绿豆面的皮，里头只夹果子或者果篦儿。不加别的。
- 鸡蛋可以自己带，论"套"买。

写法上守三条：

1. **规矩在早点铺老板娘的手上，不在旁白的嘴里。** 不解释为什么，不说"天津人如何如何"。
2. **正面写它的事件，一生里一两回。** 其余时候它只是早饭。
3. **不当段子。** 有人坏了规矩，摊主平平常常地回一句，队伍照旧往前挪。

示例：

> 你俩一人攥着一个鸡蛋排队。轮到了，老板娘接过去，在鏊子边上一磕。

> 排你前头的人问能不能加根肠。老板娘手上没停：「那您得上别处。」后头没人笑，都往前挪了半步。

> 外地回来的头一个早上，你说要一套。他问夹什么。你愣了一下：从前没人问过。

## 2. 气质

**一个平实的声音，熟悉这栋楼里的每一家，看着你俩长大，话越到后来越少。**

1. **底色不是噱头。** 见 §1。
2. **说事不说情。** 只写动作、物件、数目字，情绪让读的人自己长出来。
3. **先是两个人的事。** 每条文本先问：这对你俩意味着什么。
4. **幽默是顺带的。** 这里的人习惯拿自己的难处开玩笑，写到了就写，不为了逗而逗，也不强调它。
5. **东西会没，劲儿留着。** 楼会拆，铺子会换，人会走。写变迁时写"什么留下了"。

## 3. 从天津文学里学什么

只取手法。主调是淡，其余是偶尔一用的佐料。

| 分量 | 来源 | 学它的什么 | 不学什么 |
| --- | --- | --- | --- |
| **主调** | 孙犁晚年的文字 | 淡、省、克制，几笔写完一个人 | |
| **主调** | 冯骥才《高女人和她的矮丈夫》 | 一栋楼的眼光就是剧情；最重的感情只落在一个动作上 | |
| **主调** | 王松《烟火》 | 地方越小，时间越长；世道变而人情不变 | |
| 辅 | 冯骥才《神鞭》 | 形没了，神换个样子活着。这是全游戏写时代的方法 | 传奇色彩 |
| 辅 | 冯骥才《俗世奇人》 | 结尾收得住，从不抒情；普通人身上有一样拿得出手的能耐 | 说书腔、外号、把人写"奇" |
| 辅 | 蒋子龙、肖克凡的工厂小说 | 厂里人的直和硬；利害摆在桌面上 | |
| 辅 | 刘云若的市井言情 | 感情写在柴米油盐里；早年埋的线多年后再提 | 章回体的腔调 |
| 少量 | 林希《天津闲人》等 | 自嘲；热闹底下的凉 | 满篇闲话和打岔 |
| 少量 | 天津相声 | 小人物拿自己开涮；先把话铺稳再说 | 包袱、贯口、行话。相声的术语不进游戏 |
| 提醒 | 曹禺《日出》 | 天津不只有胡同，还有码头和河对岸的洋楼 | |

冯骥才把"天津味儿"和"天津劲儿"分开说：味儿是表面，劲儿是精神。这份手册要的是后者，写出来是这样的行为：

- 难的时候先开自己的玩笑。
- 服有本事的人，不服有钱有势的。
- 吵架吵的是理，吵完第二天照样打招呼。
- 日子紧也要把饭吃好。
- 恋家。所以"去外地"在这个游戏里是件大事。
- 你家的事就是全楼的事。帮忙的和说闲话的是同一帮人。
- 这里从来是外来人慢慢变成本地人的地方，不排外。

把这些写进人物做的事里，不要贴成标签。

## 4. 叙述声口

### 4.1 旁白

平实的第二人称白描。它熟悉这栋楼，称玩家"你"，称两位"你们"或"你俩"都可以，新旧文本不必统一。它不扮演说书人，不抖机灵，不评价。

**旁白的话随年纪变少。** GDD 里"童年的声音密，老年的声音稀"，文字同步。下面是各阶段事件正文的**上限**，写得比它短永远可以：

| 阶段 | 事件正文上限 |
| --- | --- |
| 童年 | 60 字 |
| 少年 | 55 字 |
| 青年 | 50 字 |
| 中年 | 45 字 |
| 老年 | 30 字 |

这个上限管新写的和这次改到的事件。早先写的旧事件不专门回头压，哪条被改到，就顺手压进上限。玩法重构如果换了事件的形态，再统一处理。

如果重构后事件变成一两行的人生记录，一律按老年的写法：一个动作，一个物件。

### 4.2 句法

1. **说事不说情。** 不写"你很难过"，写「你把那套煎饼果子从左手换到右手，又换回来」。
2. **短句，动词打头。**
3. **量词和数目字要准。** 一套煎饼果子、两个鸡蛋、第四十七颗星、摔了七次。
4. **留一手。** 结尾停在一个动作、一个物件或一句人话上。不总结，不升华，不写"多年以后你才明白"。
5. **对白说人话。** 街坊说的是日常的话，短，不俏皮。

### 4.3 方言

- 旁白和选项不用。街坊对白按 §1.2 的预算用。
- 靠语序和口气比靠词好。「干嘛呢你」「吃了吗您」不用任何生僻字，味儿就有了。
- 不用拟音字，不写吞字，不拿口音当笑料。
- **唐家**（南方搬来的）的孩子，台词里一直没有天津词；到了少年以后偶尔冒出一个，不要点破。这一处细节就够了，不做成系统。

### 4.4 称呼

称呼是最不费力的地方感，用对就行，不必强调。

- 街坊按身份叫：修车爷爷、早点铺的老板娘、楼长、养鸽子的大爷。现有事件里这样的叫法照旧用。带姓的叫法（陈爷、周婶）也可以，两种并存，不必统一。只有一条：不起外号。
- **两个人一起看的事件（mirror）里，有主的街坊只用身份叫。** 两位玩家读的是同一段字，其中一位可能就是这家的孩子，"周婶"就是他妈。所以写"老板娘""修车爷爷""楼长"，不写带姓的叫法，也不写"你爸""你妈"。各自的事件和家庭线里可以写"你爸""你妈"。
- 两位玩家互称"对门的"，不替玩家预设昵称。
- 楼里的孩子：大宝、二子、小四儿。
- 说住址用"几门"，不说"几单元"。

## 5. 人物

### 5.1 都是普通人

河畔里住的是普通人家。每家有自己的日子、一两样常在手边的东西、一条跟着时代走的线。

全楼至多三位街坊有一样说得上的能耐（现在是修车爷爷、楼顶养鸽子的大爷，留一个空位）。写他们的能耐要像写一个习惯，他们自己不当回事。靠一门手艺过日子的人家（扎风筝的、摔过跤的）不占这三个名额，前提是写成营生，不写成本事表演。

### 5.2 各家的底稿

每家给一个日常细节、一样物件、一条时代走向。后四户来自剧情扩充分支。

| 人家 | 日常 | 物件 | 跟着时代 |
| --- | --- | --- | --- |
| 陈家 · 自行车铺 | 补胎凑到耳边听。学生来打气不收钱 | 墙上的旧二胡 | 自行车少了，改修电动车，后来铺面换了用途。二胡还挂着 |
| 林家 · 教书先生 | 书不许折角。饭桌上也问功课 | 挂历纸包的书皮 | 教过的学生越来越多，回来看的越来越少 |
| 周家 · 早点铺 | 天不亮就起。记得每个街坊怎么吃。摊子上只夹果子和果篦儿 | 那口鏊子，装鸡蛋的小筐 | 价钱慢慢涨，摊子传给了下一辈 |
| 许家 · 跑海运 | 父亲一年回来两次，回来先睡两天 | 印着外国字的饼干盒 | 父亲上了岸，在家反倒待不惯 |
| 何家 · 姥姥带大 | 姥姥的故事每回讲得不太一样 | 针线笸箩 | 她讲过的故事，多年后被另一个人讲出来 |
| 苏家 · 裁缝铺 | 看一眼就知道尺寸。别人家的事不往外说 | 画粉，挂着的别人的新衣裳 | 做衣裳的少了，改裤脚的多了 |
| 唐家 · 南方搬来的 | 过年吃的东西跟全楼不一样 | 一坛从老家带来的菜 | 口音一点点变了，自己没发觉 |
| 吴家 · 钢厂双职工 | 爸妈倒班，饭在锅里 | 铝饭盒，脖子上的钥匙 | 厂子由盛到难，人照旧早起 |
| 顾家 · 说相声的 | 父亲在家话不多，话都留给了台上 | 一件大褂 | 茶馆冷过，又热起来 |
| 江家 · 四口挤一间 | 什么都要分。吃饭从不冷清 | 折叠床，屋当间的帘子 | 房子是一辈子的题 |
| 赵家 · 楼长 | 谁家有事都先找他 | 一大串钥匙 | 拆迁那天，他最后一个锁门 |
| 马家 · 楼顶鸽子棚 | 每只鸽子都有名字。飞丢的不找，等它回来 | 鸽哨 | 棚清了，天上偶尔还有哨声 |
| 孟家 · 开出租的 | 孩子在后座上写作业、睡觉 | 茶缸子，车里的收音机 | 车换了几茬 |
| 刘家 · 小卖部 | 小孩赊的账记在大人名下，不跟别人提 | 赊账的小本 | 小铺变成了便利店 |

剧情改写分支新增的人家照同样的格式写，同样守 §1 的预算。家里的营生写成过日子就够，不写行当里的礼数和讲究。

### 5.3 可以再加的街坊

- **海河边钓鱼的：** 天天坐着，很少见他钓上来。
- **小学传达室的大爷：** 认得每个孩子是谁家的，也认得每个孩子跟谁一块儿走。
- **楼下下棋的几位：** 楼里的事他们都知道。需要"楼里人都说"的时候借他们的嘴。

## 6. 细节库

这是备查的素材，不是清单。**按 §1.2 的预算取，一个事件一样就够。** 用普通的叫法，不解释。

- **吃：** 煎饼果子（论"套"，可以自带鸡蛋）、嘎巴菜、豆浆、果子、炸糕、熬鱼、熬白菜、冰棍、糖堆儿、烤山芋、玻璃瓶汽水。
- **玩：** 跳皮筋、拍画片、弹球、丢沙包、冰车、逮蛐蛐、放风筝、小人书；游戏厅、台球案子、旱冰场、网吧；大人养鸽子、钓鱼、下棋。
- **住：** 红砖楼、对门、暖气片、楼顶的晾衣绳和鸽子棚、楼道里堆的东西（§7）。
- **听：** 鸽哨、自行车铃、收音机、鏊子响、锅铲声、放工的车流、海河上的船笛。
- **时候：** 开春海河开冻、三伏天上楼顶乘凉、立冬白菜码进楼道、暖气来的那天、过年。

**季节只当场合，不当主题。** 过年、搬白菜、暖气来的那天，孩子的生活里本来就会碰上，写的时候让它待在背景里，事情落在两个人身上。习俗只留二月二剃头一处（§1.2）。

**写特征，不写牌名：** 二八大杠、黄色的面的、红色的小出租、铁盒的儿童霜、河上的大转轮。

## 7. 年代变迁

不写年份，只写物证。"内部参照"只给写手对表，不进游戏。

| 阶段 | 内部参照 | 楼道里堆着 | 街上 | 手里 | 大人在愁 |
| --- | --- | --- | --- | --- | --- |
| 童年 | 约九十年代 | 蜂窝煤、冬储白菜、二八大杠 | 自行车流、黄面的 | 画片、小人书、玻璃球 | 厂里的效益、分房 |
| 少年 | 世纪之交 | 山地车、纸箱子 | 红色小出租、网吧招牌 | 会嘀嘀响的小玩意儿、随身听 | 下岗、学费 |
| 青年 | 新世纪头十几年 | 电动车、小广告 | 地铁、新桥、对岸的高楼 | 手机 | 房子、去留、婚事 |
| 中年 | 往后，虚写 | 快递盒、婴儿车、轮椅 | 不写车 | 不写机器 | 父母的病、孩子、拆迁 |
| 老年 | 更往后 | 空了 | 河、桥、风 | 旧信、老照片 | 不愁了 |

1. **楼道就是日历。** 要告诉玩家时代变了，换掉楼道里堆的东西就行，不用旁白说。
2. **越往后越虚。** 中年以后不写具体的科技和潮流。
3. **三样不变：河、早点铺那口鏊子、对门。** 每个阶段让它们露一面。

**形没神在。** 写拆迁、下岗、铺子关张：写一样东西没了，再写一个习惯还在，不说破。

- 车铺换了用途，修车爷爷拿到什么东西还是先凑到耳朵边听一下。
- 厂子的大门锁了，吴师傅每天还是六点起，在阳台上站一会儿。

## 8. 两个人

默契不一定是做一样的事，更多是一个抛出去，另一个接得住。

- **共鸣写成一来一往。** 「你说『走』，对门的已经在换鞋了。」
- **错位不责怪任何一方。** 写两个人各在一处的两个画面，最好看得出都惦记着对方。
  「一个在楼顶占着两个人的凉席，一个在楼下攥着两根冰棍。」
- **同框文案看人。** 同一个行动，文案可以因为两人是谁家的孩子而不同，平实地写。
  「老板娘没让自己家孩子插队。你俩排到了，她多抓了一把葱花。」

## 9. 事件写作规范

### 9.1 各字段

字数上限取自现有事件的实际范围。

| 字段 | 上限 | 写法 |
| --- | --- | --- |
| `hint` | 15 字 | 一个动静或气味，不说是什么事。「楼道里一股熬鱼味儿。」 |
| `title` | 7 字 | 一个物件或一个动作。「脖子上的钥匙」。不用形容词 |
| `text` | 童年 60 / 少年 55 / 青年 50 / 中年 45 / 老年 30 字 | 谁、在哪、出了什么事。最多一句对白，不替玩家做反应 |
| 选项 `text` | 15 字 | 动词打头，像这个年纪的人真会做的事。不用方言词 |
| 共鸣 `text` | 48 字 | 一来一往，停在一个画面上 |
| `memory` | 8 字 | 一个握得住的东西或一个数。「四根冰棍」 |
| 错位 `text` | 47 字 | 两个画面，不责怪 |

### 9.2 写法

默认用**白描**：把事情交代清楚，停在一个画面上。另外三种按需要用：

| 写法 | 结构 | 适合 |
| --- | --- | --- |
| **埋线** | 早年出现一样东西，多年后再提一次 | 跨阶段的线 |
| **硬碰** | 利害摆上桌，每个选项都有代价，没有正确答案 | 青年中年的去留、钱、房 |
| **淡笔** | 大事小写，只给一个动作一个物件 | 病、死、离别、重逢 |

有两种写法要省着用：写某位街坊的**能耐**，全游戏三四次；让人**一笑**的收尾，有了就留，没有不凑。

### 9.3 示范

**楼顶的夏夜**

原文：
> 夏天晚上，楼顶比屋里凉快。远处海河对岸的灯一盏一盏亮起来，楼下有人在收音机里听相声。

改写：
> 三伏天，屋里待不住人。楼顶上凉席挨着凉席，谁家的收音机开着，没人认真听。

共鸣（数星星）保留原文。它已经够好了：
> 你们并排躺着，数到第四十七颗的时候，谁也想不起来数到哪儿了。

错位：
> 一个在楼顶占着两个人的凉席，一个在楼下攥着两根冰棍。

改的只是把"看风景"换成"挤着过夏天"。没有加任何天津词。

**拆迁通知**

原文：
> 楼门口贴出了拆迁通知。这栋红砖楼也在红线里。

改写：
> 楼门口贴了张红纸。全楼的人围着看，没人说话。楼长说：「今年白菜不用往楼道里码了。」

共鸣（回去拍墙上的名字）：
> 隔了很多年，同一个礼拜天，你俩在三楼楼道里碰上了。墙上两个名字还在，刻得真矮，要蹲下才拍得着。

管了一辈子楼道的人，用一句关于白菜的话送走这栋楼。这是这里的人说话的方式，不需要方言词。

**老年三例**

> 对门搬空了。你还是在楼道里咳嗽一声，才开自家的门。

> 早点铺换了第三代。你说老样子，他问：老样子是什么样？

> 果篦儿嚼不动了，换成软的。鸡蛋还是两个。

## 10. 地图与场景

不动 `content/map.yaml` 的坐标。场景的原则和文字一样：**是一栋有人住的老楼，不是天津风情展。** 地标和招牌式的元素宁少勿多，一个画面里有一两样能认出来的东西就够。

| 地点 | 定下来的东西 | 随季节和年代换的 |
| --- | --- | --- |
| 楼道 | 暖气片、两扇对开的门、墙上刻的名字（刻得矮） | 堆的东西按 §7 换 |
| 楼顶 | 鸽子棚、晾衣绳、凉席 | 夏天的凉席和西瓜，冬天冻住的床单；后来棚清了 |
| 早点铺 | 鏊子、排队的人、价钱牌、装鸡蛋的小筐 | 价钱牌上的数每个阶段改一次 |
| 楼下 | 下棋的、皮筋、小卖部的冰柜、告示栏 | 过年的红纸屑；少年时多一块网吧招牌 |
| 海河边 | 铁桥、栏杆、对岸的灯 | 春天的风筝，冬天的冰车；对岸的灯一个阶段比一个阶段高 |
| 自行车铺 | 墙上的二胡、打气筒 | 修的车按年代换，二胡不动 |
| 小学 | 传达室、校门 | 放学时门口的车在变 |

地点提示用动静和气味，不说事：「楼顶有人在弹凉席上的土。」「车铺的二胡响了一声。」

玩法由重审核心玩法的工作决定，这里只留两条和文字有关的想法，供取舍：

## 12. 自检

**不做的事**

- 不引用原作的句子，不借原作和真实字号的人物、外号。
- 不点名真实店铺、品牌、真人。
- 不写具体年份，不直接写真实的政治和社会事件。下岗、拆迁只写到一家人的饭桌上。
- 不拿外地人和口音开玩笑，不用贬称。
- 不美化耍狠。

**交稿前**

1. 把天津词换成普通话，这条还成立吗？
2. 这是你俩的事吗？
3. 有没有一样摸得着的东西？
4. 最后是不是多了一句总结？删掉。
5. 第五次读到它还行吗？
6. 数一下预算：方言词、本地细节、字数。

## 13. 小词表

街坊对白里可以用的只有这些，按 §1.2 的预算用。全国读者不用解释就懂。

| 词 | 意思 | 例 |
| --- | --- | --- |
| 嘛 | 什么 | 干嘛去？ |
| 倍儿 | 特别 | 倍儿脆 |
| 哏儿 | 有意思 | 这孩子真哏儿 |
| 甭 | 不用 | 甭等了 |
| 您了 | 您 | 吃了吗您了 |
| 得嘞 | 行了 | 得嘞，回吧 |

物件用本地的叫法，但要让人一眼能懂：煎饼果子、嘎巴菜、果子（油条）、果篦儿（薄脆）、糖堆儿（糖葫芦）、山芋（红薯）、鏊子（摊煎饼的铁板）。用了少见的字，确认游戏字体里有。

其他天津话（崴泥、打镲、拔创、褶子了之类）写手可以知道，默认不写进游戏。
