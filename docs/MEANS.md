# 家境：投胎投的是哪一扇门

> 出身决定起点，活法决定走到哪。家里有的东西能分给对门一半，但得是两个人凑到一块儿的时候。

原来家境只是三个数：开局的钱、饭菜多给的心情、投胎时多给或少给的一点属性。有钱人家的孩子过的日子和别人一模一样，只是存折上多几十块，三十岁买房几乎不看活法。

现在家境决定的是**哪些路摆在你面前**。殷实人家能花钱买路，清贫人家有自己的路，两种路都不替人长本事，线照样要自己够。

## 一、读家境的规矩

| 家境 | 标记 | 人家 |
| --- | --- | --- |
| 殷实（wealth 2） | `fam_rich` | 许家·跑海运、唐家·南方搬来的、**董家·厂长家**、**郑家·大夫家** |
| 小康（wealth 1） | 两个都不带 | 陈、林、周、苏、顾、赵、孟、刘、白、傅 |
| 清贫（wealth 0） | `fam_poor` | 何、吴、江、马、金、佟 |
| 爸妈有一头在厂里 | `fam_factory` | 陈家（妈在纺织厂）、吴家、佟家 |

- 内容里读家境只用这两个标记，小康写 `notFlags: [fam_rich, fam_poor]`。不另起 `wealth` 字段，build-content 校验 wealth 和标记一一对应。
- 殷实人家的权重从 1 调到 2，又加了两户：一个人抽到殷实的约 19%，两个人里有一个是的约三分之一。
- 殷实人家开局的钱从 90~120 降到 50~60，只比小康多二三十块。家里的钱不直接存进你的存折，要花在下面那几条路上才看得见。

## 二、关口上的路

每条挂了标记的路都写着 `lock`：标记不对的人看见这条路灰着，写着为什么。清贫人家的孩子在中考那天看得见「交择校费，过桥上重点」，旁边一行小字「家里拿不出择校费」。这一行比任何数值都让人记得住家境。

| 关口 | 殷实人家多的路 | 别的人家自己的路 |
| --- | --- | --- |
| 12 小升初 | 家里交了钱，进重点班（线 6.5，考的是 7.0；20 块） | |
| 15 中考 | 交择校费，过桥上重点（线 6.8，考的是 7.2；35 块） | |
| 18 高考 | 家里送你出国念书（线 6.3；60 块；离得最远） | 报名去当兵（看体魄 5.8；殷实人家「家里舍不得」） |
| 22 找事由 | 托家里的关系进单位（看魅力和心智 6.7，考的是心智 8.2；15 块） | 接爸妈的班进厂（`fam_factory`，不看分）/ 退伍安置进厂（当过兵的） |
| 30 安家 | 爸妈出首付，买了房（积蓄 150，自己买要 200） | 等到了厂里分的房（进了厂的，积蓄 40） |

几条规矩：

- **花钱的路有线，只是低一些，留给差一口气的人。** 中考那一关考的线 7.2、交钱的线 6.8：不上心的殷实人家孩子够得着市重点（连交钱的算上）的比小康不上心的只多几个点，远比不上清贫人家专心念书的 96%（`server/test/means.test.mjs` 钉着「殷实不上心远低于清贫专心」）。
- **钱从自己的积蓄里扣。** 十二岁交了重点班、十五岁交了择校费、十八岁出了国，三十岁那道关前面就空了一截。家底花在念书上还是留到买房，是殷实人家自己的取舍。
- **交钱进的和考进的是同一条路**（`joins`）：一个交钱、一个考进去，还是同一所学校、同一趟早班车，算共鸣，长卷上两条线并成一条。
- **清贫人家的路不看分，但天花板低**：厂里一天 14 块（坐办公室 24），稳当，三十岁能分房。
- 挂了标记的路不当兜底（`lifeMilestoneFallback`），也不摆在别人的目标条上。

## 三、日子里的事

| 行动 | 谁的 | 做什么 |
| --- | --- | --- |
| 去少年宫学琴 | 殷实，6~14 岁，放学后 | 一个钟头 2 块，魅力为主带一点心智，比自己练快 |
| 过桥上补习班 | 殷实，12~17 岁，晚上 | 两个钟头 3 块，心智比写作业快一成多 |
| 帮家里干活 | 清贫，8~17 岁 | 两个钟头挣 3 块，长体魄和见人的本事 |
| 去厂里澡堂洗澡 | 爸妈在厂里的 | 一张澡票 1 块，洗得又热又久 |

**带上对门**（`bring`，`server/src/means.ts`）：标了 bring 的事，标记不够的人本来做不了。对门正在同一个点做这件事，走过去就能跟着做，两个人算搭伴，长得一样快，两份钱都记在带的那个人头上。钱不够两份就带不了，影子不带人。

所以殷实人家的孩子学琴可以拉上对门，清贫人家的孩子能带殷实人家的孩子去工人澡堂。家里有的东西能分出去，但只在两个人凑到一块儿的时候。这就是两个人互相需要的一个理由。

帮家里干活不带人：那是你家的活（对门过来搭把手就是普通的搭伴，只是不挣钱）。

## 四、剧情

`content/events/means.yaml`：董家、郑家各三件小事（全楼头一部电话、厂里过年发的两桶油、厂子改制以后不响的电话；大夫家半夜的敲门、书架上的人体图谱、你也到了伸手摸体温表的岁数），加两件只在两家家境不一样时才有的事（琴房外头扒窗户的那一个、揣了一冬天的澡票）。写法守文风手册：不评价谁家好谁家差，不哭穷也不炫富。

主线（七章）里出身分叉的地方由主线剧情读上面的标记，不在事件选项里发路线标记。

## 五、还没解决的

- **三十岁有没有房，投胎还是比活法重。** 二十四条人生跑下来：殷实不上心 85% 有房（自己买 58%，爸妈出首付 27%），小康不上心 38%，清贫人家不进厂的几乎是 0。原因不在这次加的路上：买房线 200 正卡在积蓄最挤的地方，开局多二十几块就差二十个点，清贫人家开局 5~8 块、小康 20~40 块，这个差距早就在。要调就调开局的钱或者线本身，得用 `tools/paths.mjs` 每种活法 400 人重跑，留给下一次校准安家那一关。
- 机器人（`tools/paths.mjs` 的 `climb`）总选线最高的那条，所以「爸妈出首付」「厂里分房」这种线低但更划算的路它很少选，模拟里低估了这两条路。
- 新地图（`content/maps/`）落地以后，学琴、帮家里干活、澡堂三个点位要搬到对岸的少年宫、各家的铺子、厂区。
