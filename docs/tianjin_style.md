# 《同岁》天津文风圣经

> 味儿是皮，劲儿是骨。河畔里要的是天津劲儿。

这份文档是《同岁》所有文字和场景细节的共同底稿：写事件、写 NPC、写同框文案、写结局、画地图上的小物件，都先翻它。
它从天津文学和曲艺里提炼**气质和手法**，不搬原作的人物和句子。文中所有示例文案都是为《同岁》原创的，可以直接用，也可以照着仿。

**怎么用**

| 你要做的事 | 先看 |
| --- | --- |
| 写 / 改事件 | §4 声口、§8 双人、§9 事件规范和改写示范 |
| 写 NPC、家庭线 | §5 人物 |
| 画地图、加场景小物件、写地点提示 | §6 细节库、§7 年代、§10 地图 |
| 找新玩法灵感 | §11 提案 |
| 交稿前自检 | §12 |

**三条底线**（和 GDD 一致）：不写具体年份；不点名真实店铺和品牌；方言是佐料不是主菜。

## 1. 一句话气质

**楼下马扎上坐着个嘴不饶人、心是热的老街坊，他看着你俩长大，把你俩这辈子当一段相声说，说到最后自己先不言语了。**

五条总纲：

1. **先哏后疼。** 包袱在前，疼放在最后半句，抖完就走，不解释。
2. **说事不说情。** 只写动作、物件、数目字，情绪让读的人自己长出来。
3. **一人一绝一规矩。** 河畔里没有"路人"，每个人至少有一样拿得出手的能耐，和一条自己立的规矩。
4. **话不掉地上。** 天津人说话讲究有来有往。两个人的游戏，每句话都得有人接；真没接住，旁白替他们托一下。
5. **东西会没，劲儿留着。** 楼会拆，铺子会换招牌，人会走。写变迁不写"失去"，写"什么留下了"。

## 2. 文学谱系：从谁那里学什么

只取手法，不取人物和原句。

| 来源 | 它的气质 | 《同岁》拿来做什么 |
| --- | --- | --- |
| **冯骥才**《俗世奇人》 | 笔记体短篇，一篇只写一个人、一样绝活、一件事。说书人的口气，文白夹着俚语，结尾一句硬话收住，从不抒情。"奇"长在"俗"里。 | NPC 的写法（§5 奇人模子）。事件结尾的收法。起外号的方法。 |
| **冯骥才**《神鞭》 | 祖传的绝活撞上新时代的家伙什儿，形没了，神换个样子接着活。 | 全游戏的时代观（§7）：拆迁、下岗、铺子换代都按"形没神在"写。 |
| **冯骥才**《高女人和她的矮丈夫》 | 一栋居民楼的眼睛和嘴就是剧情。最重的感情只落在一个动作上。 | 楼里的闲话是一股力量（§5 楼里的眼睛）。老年和离别的写法（§9 淡笔模子）。 |
| **冯骥才**抢救老街的非虚构 | 拆之前，先拍下来。 | "显影"功能的叙事理由：玩家拍照这件事，本身就是河畔里人会干的事。 |
| **林希**《天津闲人》《蛐蛐四爷》《高买》 | 后人说祖上闲事的口吻，自嘲、打岔、绕着说。写闲人、玩儿家、了事的。热闹底下是家道中落的凉。 | 家庭描述、长卷题跋的声口（闲话体）。把"玩儿"写成正经事。楼长一类"管闲事的正经人"。 |
| **刘云若**《旧巷斑斓》《小扬州志》等 | 报纸连载的社会言情。写小户人家的情和义，俗而真，不清高。每回末了留个扣子。 | 两人的感情写在柴米油盐里，不写誓言。跨阶段的线索按"扣子"埋（§9）。 |
| **蒋子龙**《乔厂长上任记》《赤橙黄绿青蓝紫》 | 工厂、车间、师徒。话直，利害摆在桌面上，人有轴劲儿。青年工人有本事也有玩世不恭。 | 吴家、陈家母亲这条"厂里人"的线。青年中年的抉择事件（硬碰模子）。 |
| **肖克凡**《机器》《天津大码头》 | 工人家族的几十年，码头的行规和脾气。 | 许家跑海运的码头底色。厂子由盛到难时人的硬气。 |
| **王松**《烟火》 | 一条胡同、一百年、一群手艺人和买卖人。看的是世道怎么变而人情怎么不变，语言有曲艺的板眼。 | "一栋楼、一辈子"的结构自信：地方越小，时间越长。 |
| **孙犁**晚年文字 | 淡，省，克制。写故人旧事只用几笔。 | 老年阶段和死亡的字数与温度。 |
| **曹禺**《日出》《雷雨》 | 天津的另一半：洋楼、饭店、租界里的体面与溃败。 | 提醒我们天津不只有胡同。许家、唐家和河对岸的灯，可以带一点洋楼的影子。 |
| **相声**（马三立、高英培一路的天津相声） | 小人物自嘲，蔫哏，铺平垫稳再抖。一个逗一个捧。 | 整个双人结构的隐喻（§8）。包袱的节奏（§9 包袱模子）。 |

### 相声的四个词，全队都要会用

| 行话 | 意思 | 在《同岁》里 |
| --- | --- | --- |
| **铺平垫稳** | 包袱响之前，前面的话得老老实实交代清楚 | 事件 `text` 负责铺垫，不抢着逗 |
| **三翻四抖** | 同一个意思翻三回，第四回抖开 | 共鸣文案和长事件链的节奏 |
| **现挂** | 拿眼前的人和事即兴抓哏 | 同框文案根据两人的家庭、天赋、当天做过的事变化 |
| **捧 / 逗** | 一个出招，一个接着 | 青和梅。默契不是说一样的话，是一个抛一个接 |

## 3. 天津劲儿：七样脾气

写任何一个河畔里的人，先问他占了哪几样。

1. **哏。** 不是讲笑话，是遇上倒霉事先拿自己开涮。越难的日子越要哏，这是硬气的一种。
2. **认能耐。** 不服官，不服钱，服有绝活的。一个修车的可以让全楼敬着。
3. **立规矩。** 有能耐的人都有规矩，规矩比钱大。破了规矩，栽的是面儿。
4. **讲理讲面儿。** 吵架吵的是理，让步让的是面儿。斗气，但不较真，吵完了第二天照样打招呼。
5. **恋家。** 俗话说"借钱吃海货，不算不会过"。日子紧也要吃口好的，外头再好也惦记这口。所以"去外地"在这个游戏里天然是一件大事。
6. **热心，也嘴碎。** 你家的事就是全楼的事。帮忙的是这帮人，说闲话的也是这帮人，两样是一回事。
7. **五方杂处。** 天津是码头，九河下梢，从来是外来人变本地人的地方。河畔里不排外，只是得等你哪天自己脱口说出一个"嘛"。

**反过来，这些不是天津劲儿：** 抒情的、文艺腔的、苦大仇深的、鸡汤的、耍狠的。旧小说里的混混儿只取"硬气"和"讲规矩"，不取逞凶。

## 4. 叙述声口

### 4.1 旁白是谁

旁白就是河畔里。可以想成楼下马扎上坐了几十年的一位老街坊：全楼的事他都知道，称玩家"你"，称两位"你俩""这俩"，嘴上损，心里向着孩子。

**他的话会随着你们的年纪变少。** GDD 里"童年的声音密，老年的声音稀"，文字同步：

| 阶段 | 旁白的状态 | 事件正文字数 |
| --- | --- | --- |
| 童年 | 话密，爱打岔，爱数数，爱学人说话 | 用足，45~60 字 |
| 少年 | 开始看破不说破 | 40~55 字 |
| 青年 | 话直，利害摆出来 | 35~50 字 |
| 中年 | 话少了，一句哏一句实话 | 30~45 字 |
| 老年 | 只剩短句，不逗了 | 15~30 字 |

### 4.2 七条句法

1. **先哏后疼。** 「全楼的人围着看，看完了没人言语。末了楼长说：『得，白菜今年甭码楼道里了。』」
2. **说事不说情。** 不写"你很难过"，写「你把那套煎饼果子从左手换到右手，又换回来」。
3. **短句，动词打头，量词要准。** 一套煎饼果子、俩鸡蛋、一把葱花、半拉西瓜、一门（不说"一个单元"）。
4. **数目字要具体。** 第四十七颗星、摔了七次、三十多只鸽子。具体的数是老街坊记性好的证据。
5. **正话反说。** 夸人说「你可真行」，心疼说「活该」。让读的人自己翻过来。
6. **留一手。** 结尾停在一个动作、一个物件、或一句人话上。不总结，不升华，不写"多年以后你才明白"。
7. **一条文本一个方言钉子。** 一句里钉一个天津词就立住了，钉三个就成了方言表演。

### 4.3 方言浓度

| 谁在说 | 浓度 | 说明 |
| --- | --- | --- |
| 旁白 | 一成 | 用语序和口气，少用怪字 |
| 老辈 NPC | 四到五成 | 味儿最正的地方 |
| 同辈孩子、青年 | 两到三成 | |
| 两位玩家的选项 | 一成以内 | 玩家要代入，名字性别都是自己定的，选项保持中性 |
| 唐家（南方搬来的） | 从零开始 | 见下 |

**口音是这个游戏里的乡愁刻度。** 这是一件可以贯穿一生的小设计：

- 唐家孩子的台词起初没有天津词。哪一年第一次脱口而出一个"嘛"，哪一年就算落了户。
- 去了外地的人，选项里的天津词逐年变少；过年回河畔里那天，一下子全回来。
- 老了以后在外地接到对门的电话，第一句还是「吃了吗您了」。

**怎么写出味儿又不难读：**

- 靠词和语序，不靠拟音。写"介是嘛"，不写满篇的"似""介""揍"。
- 倒装是天津话的招牌：「干嘛呢你」「吃了吗您了」「真行啊你」。
- 吞字只当彩蛋用一两回（"派出所"说成"派所"，"劝业场"说成"劝场"）。
- 不拿口音本身当笑料。哏在事上，不在音上。

### 4.4 称呼

称呼一对，天津就立了一半。

| 场合 | 用 | 不用 |
| --- | --- | --- |
| 对陌生女性，不论年纪 | 姐姐 | 美女、小姐、阿姨 |
| 对年长男性 | 大爷、伯伯（口语读 bàibai）、师傅 | 叔叔（书面气） |
| 对同辈男性 | 大哥、二哥 | 帅哥、兄弟 |
| 敬称 | 您了 | |
| 两位玩家互称 | 对门的 | 不替玩家预设昵称 |
| 楼里孩子的小名 | 大宝、二子、三儿、小四儿、老疙瘩 | 洋气的叠字名 |
| 说住址 | 几号楼几门 | 几单元 |

## 5. 人物

### 5.1 八种人

| 类型 | 说明 | 河畔里的例子 |
| --- | --- | --- |
| **奇人** | 靠一手绝活吃饭、立着规矩的手艺人 | 修车的、摊煎饼的、裁缝 |
| **玩儿家** | 把玩儿当正经事，痴 | 养鸽子的、钓鱼的、斗蛐蛐的 |
| **闲人** | 自己没多大事，专管别人的事，了事的 | 楼长、楼下棋摊上的 |
| **嘴上的** | 靠说话吃饭，或不靠它吃饭也照样能说 | 说相声的、开出租的 |
| **厂里人** | 师徒、班组、饭盒，话直，认死理 | 钢厂的、纺织厂的 |
| **楼里的眼睛** | 没有名字的"楼里人都说" | 旁白可以借他们的嘴 |
| **外来人** | 口音不一样，慢慢变成本地人 | 南方搬来的 |
| **送行的** | 天津管操办红白事的人叫"大了"（liǎo）。他一辈子送走了半栋楼的人 | 白家（剧情改写线程新增），老年阶段的关键人物 |

### 5.2 起外号

河畔里的人互相不叫大名。两种起法：

- **行当或绝活 + 姓：** 车铺陈、果子周、一剪苏、贯口顾、哨儿马、钥匙赵、夜班孟、小铺刘。
- **排行或特征：** 二子、三儿、大胖、老疙瘩。

不要借用原作和真实字号里已有的外号。

### 5.3 奇人怎么写：绝活、规矩、物件

### 5.4 待建的 NPC 种子

- **钓鱼的二伯：** 天天在海河边坐着，没人见他钓上来过。规矩是"鱼上钩之前不说话"。
- **大了（已由白家承接）：** 楼里的白事都找他。他记得每一家老人走的那天是什么天气。
- **卖药糖的：** 只闻其声。吆喝是一段带辙的顺口溜，孩子都会背。
- **棋摊上的三位：** 永远在争一步棋，永远知道楼里最新的事。适合当"楼里人都说"的嘴。
- **传达室大爷：** 小学门口。认得每个孩子是谁家的，也认得每个孩子是跟谁一块儿走的。

## 6. 市井细节库

写场景时每条文本至少落一样**具体的东西**。按感官取用。

### 吃

- **早点：** 煎饼果子（绿豆面，夹果子或果篦儿，论"套"，可以自带鸡蛋）、嘎巴菜、老豆腐、浆子、果子、炸糕、卷圈、大饼夹一切、面茶、茶汤。
- **零嘴：** 冰棍儿、熟梨糕、药糖、糖堆儿、崩豆、棉花糖、烤山芋、糖炒栗子、玻璃瓶汽水。
- **家里：** 捞面（过生日、办喜事、搬家都吃，卤和菜码摆一桌）、熬小鱼贴饽饽、皮皮虾、螃蟹、熬白菜、窝头。
- **规矩：** 煎饼果子里不夹乱七八糟的东西。这一条可以玩一辈子的哏。

### 玩

- **孩子：** 跳皮筋、拍毛片儿、弹球儿、砍包、跳房子、抽冰嘎、推冰车、逮蛐蛐、粘知了、放风筝、租小人书、放炮（小鞭、二踢脚、呲花）。
- **少年：** 游戏厅、路边的台球案子、旱冰场、网吧、骑车去海边。
- **大人：** 养鸽子、养鸟、养鱼、斗蛐蛐、钓鱼、下棋、听相声、上桥跳水。天津人把玩儿当正经事，这些都可以出奇人。

### 住

- 红砖楼，论"门"不论"单元"。合住一套的叫"伙单"。
- **楼道就是日历：** 楼道里堆着什么，就是哪个年代（§7）。
- 楼顶：鸽子棚、晾的被子、酱缸、凉席、后来的太阳能热水器。
- 过年门窗上贴吊钱儿（镂空的红纸）。

### 听

鸽哨、自行车铃、话匣子里的相声和评书（"下回分解"）、早点铺的鏊子响、磨剪子戗菜刀的吆喝、爆米花"砰"的一声、放工时的车流、海河上的船笛、楼道里谁家炒菜的锅铲声。

### 节令

童年的日子按立春、立夏、立秋、立冬走，每个季节都有东西可写。

| 时候 | 河畔里在干嘛 |
| --- | --- |
| 立春前后 | 咬春，海河开冻，放风筝，柳絮 |
| 二月二 | 煎焖子，剃头 |
| 立夏、三伏 | 凉席上楼顶，半拉西瓜，头伏饺子二伏面三伏烙饼摊鸡蛋，海河边有人跳水 |
| 立秋 | 贴秋膘，逮蛐蛐，螃蟹上市 |
| 立冬 | 冬储大白菜码进楼道，暖气片烫手，腌菜 |
| 腊月 | 腊八泡蒜，小年吃糖瓜，贴吊钱儿 |
| 过年 | 初一饺子初二面初三合子往家转，初二姑爷回门，初五剁小人 |

### 写特征，不写牌名

## 7. 年代变迁

不写年份，只写**物证**。下表的"内部参照"只给写手对表用，不进游戏。

| 阶段 | 内部参照 | 楼道里堆着 | 街上 | 手里 | 耳朵里 | 大人在愁 |
| --- | --- | --- | --- | --- | --- | --- |
| 童年 | 约九十年代 | 蜂窝煤、冬储白菜、二八大杠 | 自行车流、黄面的 | 毛片儿、小人书、玻璃球 | 话匣子、鸽哨、吆喝 | 厂里的效益、分房 |
| 少年 | 世纪之交 | 山地车、纸箱子 | 红色小出租、网吧招牌 | 会嘀嘀响的小玩意儿、随身听 | 键盘声、流行歌 | 下岗、买断、学费 |
| 青年 | 新世纪头十几年 | 电动车、小广告 | 地铁、新桥、对岸的高楼 | 手机 | 打桩声、车站广播 | 房子、去留、婚事 |
| 中年 | 往后，虚写 | 快递盒、婴儿车、轮椅 | 不写车 | 不写机器 | 楼越来越静 | 父母的病、孩子、拆迁 |
| 老年 | 更往后，只写不变的 | 空了 | 河、桥、风 | 旧信、老照片 | 不知谁家的鸽哨 | 不愁了 |

三条写法：

1. **楼道就是日历。** 想告诉玩家"时代变了"，不用旁白说，换掉楼道里堆的东西就行。
2. **越往后越虚。** 中年以后不写具体的科技和潮流，免得过时，也因为人到了那个岁数，记住的本来就不是这些。
3. **三样不变：河、口音、早点铺那口鏊子。** 每个阶段都让它们露一面。它们是长卷上的定音鼓。

**形没神在。** 写拆迁、下岗、铺子关张，照这个顺序：先写一样东西没了，用哏说；再写一样劲儿还在，不说破。

- 车铺改成了取件的地方，陈爷还是把每个包裹凑到耳朵边摇一摇。
- 厂子的大门锁了，吴师傅每天早上还是六点起，站在阳台上看一会儿表。
- 茶馆关了那几年，顾家父亲在出租车后座上给孟师傅说了一路。

## 8. 双人：一个逗，一个捧

相声里的默契不是两个人说一样的话，是一个把话抛出去，另一个接得住。《同岁》的两位玩家天然是一对搭档。

**现在就能用的写法（不改规则）：**

- **共鸣是"接住了"。** 共鸣文案写成一来一往，而不是"你们做了同一件事"。
  例：「你说『走』，对门的已经在换鞋了。」
- **错位是"话掉地上了"，但旁白要替他们托一下。** 河畔里不让话掉地上。错位文案里让第三个人、一样东西、或者旁白接一句，疼就变成了哏里带的疼。
  例：「你在楼下喊了三声。三楼没开窗，四楼的马爷爷探出头：『甭喊了，跟他妈妈上姥姥家了！』」
- **每个默契事件备三种选项：** 一个出招的（逗），一个接着的（捧），一个不接的（独）。对应现有标签，逗多半是 `adventure` `competitive`，捧多半是 `gentle` `responsible` `patient`，独是 `solitude`。
- **同框文案要现挂。** 同一个行动，文案看两人是谁家的孩子。
  例（买煎饼果子，其中一位是周家的）：「周家婶子头也不抬：『自己家孩子也排队！』你俩排到最后，多得了一勺葱花。」

规则层面的延伸见 §11 提案 A。

## 9. 事件写作规范

### 9.1 各字段的写法

字数上限取自现有事件的实际范围，超了手机上会折行难看。

| 字段 | 上限 | 写法 |
| --- | --- | --- |
| `hint` | 15 字 | 用声音、气味、动静勾人，不说是什么事。「早点铺的鏊子响了。」「海河边有人喊：咬钩了！」 |
| `title` | 7 字 | 一个物件或一个动作，像相声的名儿。「听胎」「脖子上的钥匙」。不用形容词 |
| `text` | 60 字，老年 30 字 | 铺平垫稳：谁、在哪、出了什么事。最多一句对白，不替玩家做反应 |
| 选项 `text` | 15 字 | 动词打头，说人话，像孩子真会干的事。避免"勇敢地""默默地" |
| 共鸣 `text` | 48 字 | 抖包袱的地方。一来一往，停在一个画面上 |
| `memory` | 8 字 | 一个能握在手里的东西或一个数。「四根冰棍」「燎掉的眉毛」。不用抽象词 |
| 错位 `text` | 47 字 | 两个人各在一处的两个画面，再托一下。不责怪任何一方 |

### 9.2 六个模子

写之前先挑一个，一条事件只用一个。

| 模子 | 来源 | 结构 | 适合 |
| --- | --- | --- | --- |
| **奇人** | 俗世奇人 | 立规矩或传闻，有人不信，当场验，一句话收 | NPC 手艺人、玩儿家 |
| **包袱** | 相声 | 铺、垫、翻、抖 | 童年的哏事、同框 |
| **闲话** | 林希 | 楼里人都说如何，其实如何，只有你俩知道 | 邻里、流言、秘密 |
| **扣子** | 连载小说 | 早年埋一样东西，多年后让它响 | 跨阶段的线 |
| **硬碰** | 工厂文学 | 利害摆上桌，每个选项都有代价，没有正确答案 | 青年中年的去留、钱、房 |
| **淡笔** | 孙犁 | 大事小写，只给一个动作一个物件 | 病、死、离别、重逢 |

### 9.3 改写示范

**示范一：楼顶的夏夜（包袱模子）**

原文：
> 夏天晚上，楼顶比屋里凉快。远处海河对岸的灯一盏一盏亮起来，楼下有人在收音机里听相声。

改写：
> 三伏天，屋里待不住人。楼顶上凉席挨着凉席，不知谁家的话匣子正说到包袱口上，半个楼顶都等着乐。

共鸣（数星星）：
> 数到第四十七颗，话匣子里一抖包袱，楼顶全乐了。再数，谁也不记得数到哪儿了。

错位：
> 一个在楼顶占着两个人的凉席，一个在楼下攥着两根冰棍。冰棍化了，凉席也没人躺。

改了什么：景从"看见"换成"挤着、等着"，有人气。包袱替两个孩子打了岔，"忘了数到哪"就有了来由。错位写成两个人都惦记着对方，不是谁丢下了谁。回忆名「第四十七颗星」保留。

**示范二：听胎（奇人模子，新写）**

```yaml
title: 听胎
text: 车铺陈爷补胎不使水盆。车胎凑到耳朵边一转，手指头一按：「介儿。」有人不信，偷着拿水盆验，泡儿正从他指头底下冒。
options:
  - text: 缠着他教你听
  - text: 也端盆水去验一回
  - text: 蹲边上看他补
```

规矩、不信、验、收，四步都在 60 字里。全篇只有一个方言钉子「介儿」。

**示范三：拆迁通知（先哏后疼）**

原文：
> 楼门口贴出了拆迁通知。这栋红砖楼也在红线里。

改写：
> 楼门口贴了张红纸。全楼的人围着看，看完了没人言语。末了楼长说：「得，白菜今年甭码楼道里了。」

共鸣（回去拍墙上的名字）：
> 隔了多少年，同一个礼拜天，三楼楼道里撞上了。墙上俩名字还在，刻得真矮，得蹲下才拍得着。

改了什么：管了一辈子楼道的人，用一句关于白菜的话送走这栋楼。"刻得真矮"把几十年的时间放进了一个动作里。

**示范四：淡笔三例（老年）**

> 对门搬空了。你还是在楼道里咳嗽一声，才开自家的门。

> 早点铺换了第三代。你说老样子，他问：老样子是嘛样？

> 果篦儿嚼不动了，改夹果子。俩鸡蛋，还是俩。

## 11. 提案：从文学里长出来的玩法

这些不在当前规则里，是给后续线程和制作人的灵感，按投入从小到大排。

**A. 搭上了：互补也算默契。**
现在只有两人选一样才共鸣。相声的默契是一个逗一个捧。可以给默契事件指定一两组"搭得上"的选项对（一个喊"走"，一个去拿钥匙），触发另一种回忆。这会让游戏的默契观更准确：不必一样，接得住就行。

**B. 且听下回：每天的最后一句是扣子。**
学连载小说，一天结束时旁白留一句，预告下一个日子的默契事件或呼应一条埋着的线。
例：「海河今儿夜里冻实了。」「对门的灯比你家多亮了一个钟头。」

**C. 口音刻度。**
见 §4.3。给选项和文案加一个"口音"变体，随家庭和距离变化。长卷上可以画成一条时浓时淡的线。

**D. 柜顶上的娃娃哥。**
天津有"拴娃娃"的老俗：到娘娘宫求一个泥娃娃回家当长子，所以亲生的头一个孩子排老二，泥娃娃是"娃娃大哥"；隔些年还要送去重塑，让它跟着长岁数，这叫"洗娃娃"。这和《同岁》撞得很巧：

- 投胎时，家里柜顶上已经坐着一位泥捏的大哥。「所以你一落生，就是老二。」
- 每进一个人生阶段，娃娃哥"洗"一回：肚兜换成学生装，后来长了胡子。它是一个不说话的同岁人。
- 玩家离线时的"影子"可以落到它身上：「你不在的那天，是柜顶上那位替你去的。」
- 人走了，泥娃娃还在。长卷的落款可以是两个并排的泥娃娃。

**E. 长卷题跋用闲话体。**
结局统计现在是一句陈述。可以学后人说祖上闲事的口吻再加一句。
例：「这二位，对门住了一辈子，煎饼果子吃了一千多套，正经话没说过几句。」

**F. 显影即抢救。**
拆迁事件之后，给"显影"一个剧情入口：楼要拆了，去把它拍下来。玩家拍现实里的老楼、老照片，线稿进长卷。功能和主题在这里合上。

## 12. 禁区与自检

**不做的事**

- 不引用原作的句子，不借原作和真实字号的人物、外号。
- 不点名真实店铺、品牌、真人。公共地理写到"河、桥、老城、海边"为止。
- 不写具体年份，不直接写真实的政治和社会事件。下岗、拆迁只写到一家人的饭桌上。
- 不地域黑，不用贬称，不拿外地人和口音开涮。包袱抖在自己身上，或抖在比自己强的人身上。
- 不美化耍狠和欺负人。
- 不用影视剧和网络上已经用烂的天津梗。
- 不把天津写成一张只有相声和煎饼的明信片。要有工厂、码头，和河对岸的洋楼。

**交稿前过五关**

1. **哏关：** 这条里有没有一处让人嘴角动一下？老年和淡笔模子除外。
2. **物关：** 有没有一样摸得着的东西，一个准确的量词或数目字？
3. **人关：** 出场的 NPC 有没有用上他的绝活、规矩或物件？
4. **接关：** 两个人的话有没有掉地上？掉了有没有人托？
5. **收关：** 最后一句是不是停在动作、物件或人话上？有没有多出一句总结？删掉它。

再查两样：方言钉子是不是只有一个；字数有没有超 §9.1 的上限。

## 附：延伸阅读与核实说明

想把味儿吃透，按这个顺序读，每本带着一个问题：

1. 冯骥才《俗世奇人》：他是怎么用最后一句话收住一个人的？
2. 冯骥才《神鞭》：绝活没了以后，人靠什么站着？
3. 林希《天津闲人》《蛐蛐四爷》：说闲话的口气是怎么带出凉意的？
4. 冯骥才《高女人和她的矮丈夫》：全篇最重的那一下，为什么是一个举伞的动作？
5. 蒋子龙《赤橙黄绿青蓝紫》：有本事的年轻人为什么偏要吊儿郎当？
6. 王松《烟火》：一条胡同怎么装下一百年？
7. 马三立的单口小段：一个包袱之前，他铺了多久？

**核实说明：** "味儿与劲儿"的说法、林希和王松作品的概况、那句吃海货的俗话、吞字的例子，写的时候在网上对过出处。其余作家作品和相声行话是文学史和曲艺里的常识，没有逐条再查。民俗细节（拴娃娃和洗娃娃、"大了"、妈妈例儿、各节令的吃食）和词表的释义依据通行说法整理，没有找到文献逐条对证。正式进游戏之前，建议请一位天津本地的长辈过一遍。
