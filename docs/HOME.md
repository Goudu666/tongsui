# 家里的东西：同一年，三户人家不在同一个年代

> 两个人同一年生、住对门。可对门家里先有了电视、书柜、电脑，你家还没有。

[MEANS.md](MEANS.md) 第八到十节把三档人家写成三种难度：清贫的时间是借来的，小康的什么都够一点，殷实的路是铺好的。那几节管的是时间、钱和爸妈的期望。这一篇管**家里有什么**：同一年，殷实人家早几年过上了下一个年代，清贫人家晚几年，有的东西一直没有。这些东西都能用，用了长东西；没有的，去对门家用，或者自己攒钱买。

## 一、一样东西哪一年进门（`content/home.yaml`）

年份是日历年（出生年 + 岁数，`content/eras.yaml`），只给引擎算，不给人看。殷实比小康早五六年，小康比清贫再早五到十年，大致照城里人家的先后摆：

| 东西 | 殷实 | 小康 | 清贫 | 收起来 | 按人家改的 |
| --- | --- | --- | --- | --- | --- |
| 收音机 | 1958 | 1962 | 1970 | 1998 | 顾家（说相声的）1952 |
| 电视 | 1979 | 1984 | 1990 | | |
| 冰箱 | 1985 | 1991 | 1999 | | 刘家（楼下小卖部）1986 |
| 一柜子书 | 1960 | 1993 | 一直没有 | | 林家（教书先生）1972、金家（老城里搬来的，穷了书还在）1950、郑家（大夫家）1955 |
| 订的牛奶 | 1980 | 1994 | 一直没有 | | |
| 电话 | 1990 | 1996 | 2002 | 2016 | 刘家 1989 |
| 游戏机 | 1991 | 1996 | 一直没有（1992 起能买，12 块） | 2007 | 许家（跑海运）1989 |
| 复读机 | 1994 | 1999 | 一直没有（1995 起能买，15 块） | 2012 | 许家 1990 |
| 电脑 | 1998 | 2004 | 2012 | | 2000 起能买，60 块 |

所以生在哪个年代，差的东西也不一样：六十年代中生的，十五岁时殷实人家有电视、清贫人家还没有；九十年代初生的，电视家家都有了，差在书柜、复读机和电脑（殷实人家五六岁就有电脑，小康十二岁，清贫二十岁）。

身上的标记是 `hm_<id>`，意思是「这个人爸妈家里有」。事件、关口都能用 `requires.flags` 读它（比如人际那条线托人时「家里有电话」读 `hm_phone`）。

规矩（`server/src/home.ts`）：

- 投胎那一刻悄悄摆上生下来就有的；往后每过一天（`homeSync`，在 `eraTick` 后面）到了年份的进门，三岁以后进门的记一条长卷（`kind: "home"`，`home: { role, item, name }`），客户端弹一行「家里添了 · 电视」或者「对门家添了电视」。
- 已经进门的不收走：家道中落（`fam_fallen`，摘了 `fam_rich`）以后新进门的按小康算，原来有的照样摆着。到了 `gone` 那一年家家都收起来（座机让手机顶了，复读机、游戏机没人用了）。
- 爸妈走了（`parent_gone`）以后，家里不再添东西。

## 二、东西能用（`content/map.yaml` 末尾的 `hm_` 行动）

挂在两家屋里原有的点位上：饭桌边是电视、收音机、游戏机、糊纸盒；书桌边是书柜、复读机；屋角是电脑。**都是 menu**（只在菜单上点到才做），机器人、影子、旧安装包轮不到，原来校准过的活法数一个不动。

| 行动 | 要家里有 | 年纪 | 一个钟头 | 为什么 |
| --- | --- | --- | --- | --- |
| 翻家里的书 | 书柜 | 6~29 | 心智 0.34 | 比写作业（0.4 / 90 分钟）快三成，和爸妈报的班一个量级。累得也轻 |
| 跟着磁带念英语 | 复读机 | 10~21 | 心智 0.22、魅力 0.12 | |
| 用电脑查东西 | 电脑 | 10 起 | 心智 0.3、魅力 0.05 | |
| 听广播 | 收音机 | | 心智 0.12，心情 +6 | 六七十年代的孩子，评书就是课外书 |
| 看电视 | 电视 | 中午以后 | 魅力 0.04，心情 +12 | 心情好学得快（`worldEfficiency`），可一个钟头也就没了 |
| 打游戏机 / 打电脑游戏 | 游戏机 / 电脑 | | 心情 +16 / +18，精力掉得多 | 殷实人家的孩子诱惑也多 |
| 喝门口的牛奶 | 订的牛奶 | 15 以前，早上 | 体魄 0.03，十分钟 | 一天一瓶，十几年下来是一截个子 |
| 帮家里糊纸盒 | （清贫人家） | 12~17，傍晚以后 | 挣 1 块 | 二十二岁坐办公室头一年要自己垫 21 块（MEANS 第十节）：念书还是挣钱，时间只有一份 |

`menu.test` 第 5 节「菜单上后添的事不超过原来最快的」不算 `requires.home` 的事：和挂 `requires.flags` 的一样，那是资源差异，本来就该快。

### 去对门家用

`requires.home` 看的是**点位那一户**（点位所在屋子的 owner；楼道、街上没有 owner 的看自己家）。所以清贫人家的孩子走到对门屋里，对门家的书柜、电视、游戏机都能用，长得一样快：东西是对门的，时间是自己的。两个人一起用同一样就是搭伴（成长 ×1.5、心情、亲近）。锁上时一句话：自己家没有写「家里没有这样东西」，对门家没有写「TA 家没有这样东西」。

两个人要是一家穷一家富，穷的那个的童年有一半是在对门客厅里过的；两家都穷，那就都没有。这是投胎投出来的。

### 自己攒钱买（`buys`）

游戏机、复读机、电脑写了 `buy`：家里没有、外头有卖的（`from` 年以后、`gone` 以前）、到了岁数，就能在自己家点「攒钱买……」，扣钱，这户人家就有了（对门也能过来用），记一条长卷（`home.bought`）。只在自己家买（「这不是你的家」）。钱数和价对得上由 build-content 查。

## 三、给客户端的

- WORLD 新加 `homes: { qing: [物件 id], mei: [...] }`（两户这会儿各有什么，客户端照着摆屋里的东西）和 `buys: { qing: [行动 id], mei: [...] }`（这会儿在自己家买得了的）。都是新加的字段，协议号不动。
- 行动新字段 `requires.home`（物件 id 列表）、`buys`（物件 id）。旧客户端不认，点上去服务器回一句锁的话。
- 日志新 kind `"home"`，旧客户端不认的 kind 跳过。
- 屋里的画：两家按 `homes` 和家境摆东西（清贫人家屋当间一道布帘子、折叠床；殷实人家地板革、沙发），在 `tools/art/` 和 `client/scripts/world/` 里，见那边的说明。

## 四、怎么验

- `server/test/home.test.mjs`：同一年三档人家有的不一样、人家写了的压过家境、年代不一样差的也不一样、到了年份进门记长卷、收起来的摘掉、爸妈走了不再添、去对门用、两人一起是搭伴、攒钱买只在自己家、不点菜单的轮不到、翻书比写作业快三成。
- `tools/paths.mjs` 新加两种活法：「念书，用家里的」（菜单上看自己家的东西）、「念书，去对门借」（也去对门家）。`node tools/origin.mjs 20 一个人念书 念书，用家里的` 看三档拉开多少。

## 五、量出来的

`UNTIL=23 node tools/origin.mjs 20 念书，不碰家里的 念书，用家里的`（两个人放进同一档人家，按每分钟长多少挑事；合了 MEANS 第十节坐办公室要垫 21 块以后）：

```
活法	出身	中考重点	办公室
念书，不碰家里的	清贫	68%	34%
念书，不碰家里的	小康	85%	78%
念书，不碰家里的	殷实	93%	97%
念书，用家里的	清贫	68%	37%
念书，用家里的	小康	95%	78%
念书，用家里的	殷实	100%	100%
```

会用家里东西的人，小康、殷实的中考各多十个、七个点；清贫人家家里什么都没有，用不用一个样。三档的差从 25 个点拉到 32 个点。

一家穷一家富住对门（青是清贫人家，两个人都「念书，去对门借」，scratchpad 探针，每格 24 世）：对门是殷实人家，青的中考市重点 67% → 83%；对门也是清贫人家，还是 67%。**对门是谁家，童年就不一样。**
